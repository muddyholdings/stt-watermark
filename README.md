# stt-watermark

Inaudible spread-spectrum audio watermark for AI-generated speech.

Used by [STT.ai](https://stt.ai) on every clip produced by `/v1/tts` (F5-TTS voice cloning) to satisfy [EU AI Act Article 50](https://artificialintelligenceact.eu/article/50/) machine-readable AI-content disclosure requirements (effective 2026-08-02).

The detector is open-source so any third party can independently verify "this clip was generated by STT.ai" without trusting our word for it.

## Status

Alpha (v0.1). Not yet on PyPI. See the README below for the algorithm and robustness gates.

## Install

```bash
pip install stt-watermark   # not yet published
```

## Quick start

```python
import soundfile as sf
from stt_watermark import embed, detect

audio, sr = sf.read("speech.wav")
watermarked, info = embed(audio, sr)
sf.write("speech_wm.wav", watermarked, sr)

result = detect(watermarked, sr)
print(result.found, result.payload.hex(), result.confidence)
```

## CLI

```bash
stt-watermark embed in.wav out.wav --creator-id 42 --transcript-id abc123
stt-watermark detect file.wav
stt-watermark detect file.wav --json
```

## Algorithm

Spread-spectrum (DSSS) in the STFT magnitude domain, mid-frequency band (2–6 kHz), 128-bit payload (magic + creator_id + transcript_id_hash + CRC). Pure NumPy + SciPy, CPU-only, no torch.

See https://stt.ai for details.

## Robustness (v0.1 targets)

| Transform | Detection rate | BER |
|---|---|---|
| MP3 320 kbps | 100% | 0% |
| MP3 128 kbps | ≥ 90% | < 5% |
| AAC 128 kbps | ≥ 90% | < 5% |
| Opus 64 kbps | ≥ 80% | < 10% |
| ±5% speed | ≥ 90% | n/a |
| EQ ±3dB | ≥ 95% | < 2% |
| 20 dB SNR noise | ≥ 90% | < 5% |

Adversarial removal is **not** in scope — see threat model.
